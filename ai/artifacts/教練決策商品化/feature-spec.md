# 功能規格書

## Metadata

- 功能：教練建議頁的決策優先資訊層級
- 負責人：Codex（使用者授權選定試點）
- 狀態：已實作
- 風險等級：低

## 問題

目前教練建議頁把內部 resolver 術語、同步健康狀態、決策理由與下一堂行動同列呈現。跑者在手機上無法快速回答「本週是否照跑、下一堂是什麼」。

## 目標

- 先呈現本週結論與下一堂正式課表。
- 把 Garmin 判讀保留為可展開的證據，不刪除也不複製資料。
- 不改變正式課表、Garmin 同步、教練記憶或歷史週的資料契約。

## 非目標

- 不調整訓練處方、放行規則或任何 API。
- 不重寫既有的空、錯誤、鎖定或歷史評估行為。

## 使用者故事

| 故事 | 身為／我想要／以便 | 驗收標準 |
|---|---|---|
| 決策導覽 | 身為跑者，我想先看到本週結論與下一堂課，以便立刻知道該做什麼。 | 桌面與手機都先顯示結論、下一堂與查看正式課表動作。 |
| 證據追溯 | 身為跑者，我想需要時才展開 Garmin 判讀，以便可驗證決策但不被資料淹沒。 | Garmin 指標與既有文案仍可展開讀取。 |

## 驗收標準

- 不再向使用者顯示「same course resolver」等內部實作術語。
- Garmin 判讀在決策與下一堂課之後，且可鍵盤展開。
- `npm run ui:check`、`npm run trainer:logic`、`npm run ui:layout` 與 `git diff --check` 通過。
