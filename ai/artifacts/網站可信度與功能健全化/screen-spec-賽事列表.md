# 畫面規格

## Metadata

- 功能：網站可信度與功能健全化
- 畫面：公開賽事列表
- 狀態：草稿

## 目的

讓跑者先判斷資料是否最新，再以手機友善的賽事卡完成查看、收藏、標記報名、排課與前往官方頁；完整事實仍可按需展開。

## 版面配置

- 主要區域：資料狀態列、賽事身份（日期／名稱／地點／距離／報名狀態）、主要行動。
- 次要區域：決策摘要、資料可信度、費用／名額／開跑時間等完整事實。
- 導覽：沿用既有 Nav 與賽事篩選。
- 動作：用這場排課、官方報名、加入行事曆、收藏、已報名、展開完整資訊。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設 | 顯示最後更新時間與已同步狀態 | 不適用 | 桌機／手機截圖 |
| 載入中 | 狀態列顯示載入，不宣稱同步 | 正在確認賽事資料… | DOM／截圖 |
| 空狀態 | 保留篩選復原入口 | 目前沒有符合條件的賽事 | DOM |
| 錯誤 | 顯示載入失敗與安全重試 | 賽事資料暫時無法載入，請重新整理 | DOM／鍵盤操作 |
| 停用 | 無官方連結或不可排課時停用對應按鈕 | 連結待補／日期已過 | DOM |
| 權限不足 | 公開資料不需登入；本機管理入口不出現 | 此功能只在本機提供 | smoke test |
| 行動裝置版 | 首層只留決策必要資訊，次要事實收合 | 同上 | 390px layout test |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 展開完整資訊 | 有事實資料 | 顯示開跑、費用、名額、主辦與來源 | 無資料時不顯示控制項 |
| 重新載入 | JSON 載入失敗 | 重試既有資料載入 | 仍失敗則保留錯誤狀態 |
| 標記收藏／已報名 | 本機儲存可用 | 更新狀態與計數 | 儲存不可用時不偽稱成功 |
| 用這場排課 | 未過期且距離可辨識 | 進入既有排課流程 | 條件不足時按鈕停用 |

## 設計系統對照

- 用到的既有 design token：`--ink`、`--muted`、`--soft`、`--surface`、`--line`、`--green`、`--green-dark`、`--yellow`、`--radius`、`--radius-sm`、`--shadow-soft`。
- 用到的既有元件：Nav、Card、Button、賽事事實列、Input／Select、既有 trust pill。
- 本畫面新做的元件：無；資料狀態以既有卡片／pill 語言組成，若核准後實作僅新增語意 class，不建立新視覺系統。

## 視覺驗收標準

- 390px 卡片不超過既有 layout test 高度門檻。
- 日期、名稱、距離、報名狀態與主要動作不被截斷。
- 詳細事實可展開且鍵盤可操作。
- 正常、待同步、錯誤三種狀態不能只靠顏色辨識。
- 色彩、字體、間距、圓角與陰影均沿用既有 token。
