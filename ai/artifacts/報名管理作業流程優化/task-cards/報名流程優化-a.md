# 任務卡：報名流程優化 A

## 範圍

- 首次新增隊員時，直接顯示所有必填個資與完成摘要。
- 帶入賽事後，以內嵌三步流程列導引選人、選組別與建立報名。
- 阻擋「已繳費但未報名」的單筆與批次狀態矛盾。
- 讓已選報名紀錄可一鍵標示為已報名或已繳費；繳費動作自動保證已報名。
- 報名紀錄每頁筆數提供 5、10、15、20 與全部選項，切換時回到第一頁。
- 人員名單每頁筆數提供 10、20、30、40、50 與全部選項，切換時回到第一頁。
- 人員與報名清單的每頁筆數選擇各自保存在本機瀏覽器設定，重整後恢復。
- 將既有靜態驗證擴及模組化後的報名程式來源。

## 非範圍

- 不變更 API、資料格式、localStorage key、Excel 匯入匯出、通知或備份流程。
- 不重整既有報名工作區整體視覺架構。

## 驗收契約

1. 新增人員畫面能看見九項必填資料及完成數；原生驗證失敗會展開欄位區。
2. 帶入賽事後，流程列能反映選人、組別與可儲存狀態，並聚焦第一位可選隊員。
3. 未報名的資料無法標為已繳費，單筆與批次皆提供清楚錯誤。
4. 既有 UI 檢查、報名管理驗證、JavaScript 語法檢查與 diff whitespace 檢查皆通過。
