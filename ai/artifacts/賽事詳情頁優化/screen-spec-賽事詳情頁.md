# 畫面規格

## Metadata

- 功能：賽事列表至賽事詳情頁優化
- 畫面：賽事詳情頁
- 狀態：A 已選定；產品化精修待人工複核

## 目的

讓跑者在一個明確的決策頁中完成「這場是否適合我、何時何地、如何報名／加入行事曆／納入課表」；列表不再承擔完整事實卡責任。

## 版面配置

- 主要區域：返回列表與 Runner Plaza 情報脈絡、標題、地區／難度／報名狀態、距離、報名期與資料可信度；桌面右上是「用這場排課」唯一主要動作。
- 次要區域：日期主視覺、活動地點、官方報名與行事曆／收藏／已報名操作、目前狀態／最早開跑／名額摘要、開跑／費用／名額／主協辦資訊卡。
- 導覽：保留既有網站導覽；詳情內有顯性的「返回賽事列表」。
- 動作：用這場排課、官方報名、加入行事曆、收藏、標示已報名、查看地點與交通資訊。

## 狀態

| 狀態 | 必要行為 | 空狀態／錯誤文案 | 驗證方式 |
|---|---|---|---|
| 預設 | 呈現所有可用欄位與行動 | 無 | 桌面截圖與 DOM |
| 載入中 | 顯示與詳情骨架相同的預留高度 | 正在載入賽事資訊 | 截圖 |
| 空狀態 | URL 對應賽事不存在時提供返回列表 | 找不到這場賽事，請回到列表重新選擇。 | DOM 與點擊 |
| 錯誤 | 資料讀取失敗時提供重試或返回 | 賽事資料暫時無法讀取。 | DOM |
| 停用 | 已過期／停辦禁用排課；報名不可用須有原因 | 賽事已過／活動停辦 | DOM 與點擊 |
| 權限不足 | 本公開頁無權限狀態 | 不適用 | N/A |
| 行動裝置版 | 390px 單欄，行動順序為標題、主行動、日期、地點、操作、事實卡 | 無 | 390px 截圖 |

## 互動

| 動作 | 觸發條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 返回列表 | 點選返回連結 | 還原列表與篩選 URL 狀態 | 無 |
| 用這場排課 | 未過期且未停辦 | 沿用既有 Trainer 排課流程 | 過期／停辦時 disabled |
| 官方報名 | 有官方或公開資訊連結 | 新分頁開啟既有安全外連 | 缺連結時顯示待補且不可點 |
| 加入行事曆 | 點選行事曆控制項 | 沿用 Google Calendar／ICS／複製資訊選單 | 無 |
| 收藏／已報名 | 點選切換控制項 | 沿用 localStorage 與 aria-pressed | localStorage 例外時沿用既有保護 |

## 設計系統對照

- 用到的既有 design token：`--ink`、`--muted`、`--soft`、`--surface`、`--line`、`--green`、`--green-dark`、`--yellow`、`--radius`、`--radius-sm`、`--shadow-card`、`--shadow-soft`、既有 4/8/12/16/24/32 間距及字級 scale。
- 用到的既有元件：Button、Card、賽事事實列、Nav。
- 本畫面新做的元件：賽事詳情 Hero 與事實卡區（僅以現有 Card／賽事事實列組合；實作完成後登記進 inventory）。

## 視覺驗收標準

- 桌面首屏採三欄：賽事身分與可信度、日期與地點、唯一主行動；不得在標題與排課按鈕之間留下無用途的空白區。
- 資訊層次固定為：賽事身分、可信度與主行動 → 日期／地點／官方操作 → 三項決策摘要 → 賽事事實。
- 桌面不讓「官方報名」與「用這場排課」競爭同一優先級：後者為唯一填色主要按鈕。
- 事實卡只顯示有資料的欄位，不用空白卡硬湊格線。
- 以背景、留白與輕量陰影區隔；不疊加厚邊框、重陰影與額外背景。
- 所有色彩、字體、間距、圓角、陰影一律取自 design system；手機觸控目標至少 44px。
