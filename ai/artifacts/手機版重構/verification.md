# 手機版重構驗證

- 2026-11-17：使用者選擇方案 A。調整手機共用導覽、內容頁與訓練頁佈局，並為登入、同步與教練週報密碼加入顯示切換。
- 同步視窗切換時，關閉前一視窗的延遲焦點回復不再蓋過新視窗；模擬測試覆蓋先關後開。這是找到的焦點競爭問題，尚不能證明它是手機上所有跳動的唯一原因。
- `npm run trainer:logic`、`npm run check`、`npm run build` 與 `git diff --check` 通過。隔離測試涵蓋顯示／隱藏密碼、保留輸入與選取範圍；測試使用合成資料。
- 啟動 43128 隔離本機服務，在同一程序讀取訓練頁回 HTTP 200 並確認新版資源引用；未接觸正式帳號或資料。
- 原 `npm run check` 一度因快取版本硬編碼失敗，更新驗證條件與新版本一致後通過。獨立服務跨工具請求一度遭重置，改為同程序檢查後通過。
- 專案禁止瀏覽器控制：沒有螢幕截圖、人眼視覺驗收、手機虛擬鍵盤、真機兩裝置登入或所有頁面互動驗收。全站版面目前是共用第一批調整，不能宣稱每頁手機版已驗收完成。
- 滑動穩定性：手機寬度下不再以 JavaScript 固定訓練工具列或插入動態占位，桌機仍保留原固定方式；橫向月份／分頁／表格區限制水平捲動傳遞。模擬測試覆蓋手機滑動、桌機固定及縮成手機尺寸；`npm run trainer:logic`、`npm run check`、`npm run build`、CSS 語法與 43129 本機 HTTP 檢查通過。實際手機滑動尚未驗證，尚不能認定這是所有頁面跳動的唯一原因。
