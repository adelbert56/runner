# 手機版畫面規格

## Metadata
- 功能：Runner 網站手機版重構；畫面：賽事、訓練、同步；狀態：草稿。

## 目的與配置
- 用手機找到賽事、查看今天課表、登入同步。使用既有頂部品牌及底部六項導覽，主要內容為單欄。
- 本輪比較列表與訓練頁階層，保留所有現有動作、真實資料、帳號權限、個人資料與備份流程。

## 狀態
| 狀態 | 必要行為 | 驗證方式 |
|---|---|---|
| 預設／有資料 | 手機單欄、主動作清楚、內容不橫向溢出 | DOM／尺寸檢查 |
| 載入中／錯誤 | 明示進度或原因，保留重試 | 邏輯測試 |
| 空狀態／權限不足 | 指出可做的下一步，不假稱已有資料 | DOM 檢查 |
| 停用 | 說明原因、不可誤觸 | DOM 檢查 |
| 行動裝置 | 320、375、390、430px，安全區及鍵盤不遮主要操作 | 尺寸檢查，真機待驗收 |

## 互動
| 動作 | 條件 | 結果 | 失敗情境 |
|---|---|---|---|
| 切換頁面 | 底部導覽 | 顯示對應頁並保留原流程 | 清楚顯示錯誤 |
| 顯示密碼 | 同步或登入密碼輸入 | 切換明文與隱藏，保留輸入和游標，不送出表單 | 不記錄密碼 |
| 登入同步 | 已輸入帳密 | 顯示處理狀態，接續解鎖 | 視窗內顯示錯誤 |

## 設計系統對照
- 既有 token：`--surface`、`--soft`、`--line`、`--ink`、`--muted`、`--green-dark`、`--radius`。
- 既有元件：Button、Input、Card、底部導覽、賽事列、練跑儀表板、週曆詳情。
- 新元件：密碼欄附可見性切換按鈕；選定方案後依既有 Input／Button 製作並登記 inventory。

## 驗收
- 各頁文字、資料與操作不因手機版裁切、遮擋或消失；同步輸入不中斷，眼睛按鈕有無障礙名稱與焦點狀態。
- 桌機既有流程、加密資料與訓練紀錄不受影響。專案禁用瀏覽器控制，未取得人眼或實機證據不得聲稱視覺驗收通過。
