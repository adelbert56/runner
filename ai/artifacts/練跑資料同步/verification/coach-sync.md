# 練跑資料同步驗證

本機驗證通過。正式站發佈與真實帳號雙裝置驗收待執行。

## 變更

- 教練密語通過驗證且使用者選擇記住時，沿用現有同步排程補傳加密快照。
- 訓練資料一致且雲端快照缺少密語時，自動補傳一次。另一台裝置可沿用既有的週報載入流程。
- 雲端有更新且本機仍符合上次同步版本時，自動載入新資料。套用前再次比對本機狀態，保留同步期間的輸入。雙端有差異時沿用現有衝突處理與備份。

## 驗證

| 指令或證據 | 結果 |
| --- | --- |
| `npm.cmd run check` | 通過程式語法與靜態檢查。新增的記住密語觸發條件也通過獨立 `ui:check`。 |
| `$env:UI_LAYOUT_BROWSER_CHANNEL='chrome'; npm.cmd test` | 通過靜態檢查、桌機與手機等視窗尺寸回歸及訓練邏輯。使用隔離 Chrome。 |
