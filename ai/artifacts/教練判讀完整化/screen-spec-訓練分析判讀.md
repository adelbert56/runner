# 畫面規格：訓練分析判讀

## Metadata

- 功能：教練判讀完整化
- 畫面：訓練頁／進度 tab／訓練分析
- 狀態：A 版已實作；陪伴課型一致性已巡檢

## 目的

讓跑者在同一個判讀面板看懂「這次資料可否用於配速與課表決策」及下一步，而非只看原始數字。

## 版面配置

- 主要區域：一張「本週放行判讀」卡，先顯示結論與下一步。
- 次要區域：地形／天氣、恢復、賽事、補給四個證據列。
- 動作：展開詳細證據、補登賽後 48 小時與補給資料。
- 導覽：沿用現有 progress tab；不新增 tab 或平行課表。

## 狀態

| 狀態 | 必要行為 | 文案 |
|---|---|---|
| 預設 | 顯示結論、四類證據與下一步 | 可用／觀察／保護中 |
| 載入中 | 顯示既有卡片 loading | 正在讀取 Garmin 詳細資料 |
| 空狀態 | 保留下一步 | 尚無可用的地形或恢復資料 |
| 錯誤 | 降級總爬升 | 詳細地形資料未取得，不以坡度校正配速 |
| 停用 | 賽後 48 小時未滿 | 後續速度與長跑維持 |
| 權限不足 | 本機外不可讀個資 | 詳細資料僅在本機訓練頁分析 |
| 行動裝置 | 證據列單欄、主要結論最先 | 觸控目標至少 44px |

## 設計系統對照

- token：`--surface`、`--soft`、`--line`、`--green-dark`、`--yellow`、`--radius`、`--shadow-card`。
- 元件：既有 Card、Button、狀態標籤與進度分析區。
- 新元件：判讀證據列；沿用 Card 與細分隔線，不新增色彩或陰影。

## 視覺驗收標準

- 主要結論在桌面與手機都先於證據閱讀。
- 四類證據不另立四張卡，避免資訊碎裂。
- 無資料與資料錯誤明確區分。
