# 功能規格書：單堂主課教練判讀升級

## Metadata

- 功能：把 Garmin 單堂主課的原始分段轉為可追溯、可行動的教練評論
- 負責人：Squall
- 狀態：已實作（C 版）
- 風險等級：中

## 問題

目前單堂報告正確地把主課與熱身／收操分開，卻只顯示「最近兩次同課型」與後半心率差。跑者看得見數字，仍無法快速知道是否符合本堂處方、差異是否可比較、該維持或調整下一次訓練。

## 使用者

使用 Garmin 同步並依正式課表訓練的跑者。

## 目標

- 先給出本堂結論與唯一下一步，再揭露證據。
- 分別說明：課表目標對照、主課完成度、配速／心率／步頻趨勢、資料品質與比較信心。
- 沒有 Garmin 明確主課標籤、可比樣本不足或環境不宜比較時，明確降級，不做能力或課表升級推論。
- 使用既有 Garmin、課表與自我評量資料；不要求跑者重複填手錶已有資料。

## 非目標

- 不依單趟表現自動改寫正式課表、比賽目標或心率上限。
- 不把自動公里圈假裝成主課段別。
- 不建立平行課表、不做醫療診斷，也不新增 GPS 軌跡保存。

## 使用者故事

| 故事 | 身為／我想要／以便 | 驗收標準 |
|---|---|---|
| US-1 | 跑者想先知道這堂品質課如何，以便決定下一次是否照原課表跑 | 開啟報告 5 秒內可看到結論、依據範圍與唯一下一步。 |
| US-2 | 跑者想知道快慢是否真的可比較，以免被單趟數字誤導 | 顯示比較對象、樣本數、可比較限制與信心，不足即降級。 |
| US-3 | 跑者想知道配速變化的代價，以便照顧恢復 | 同時呈現主課配速、心率漂移、步頻一致性及已知環境註記。 |
| US-4 | 跑者想追溯判讀，以便確認教練沒有黑箱 | 每項結論可連回正式課表目標、Garmin 主課範圍與分段明細。 |

## 功能需求

- WHEN Garmin 有明確 MAIN／ACTIVE／INTERVAL 步驟標籤，THE SYSTEM SHALL 只以該主課範圍計算品質指標，並保留完整課程負荷。
- WHEN 同日有正式課表，THE SYSTEM SHALL 顯示課表目標與實際主課的差異；缺任一目標資料時 SHALL 顯示「無法對照」，不得推定達標或未達標。
- WHEN 至少兩筆同課型可比較主課存在，THE SYSTEM SHALL 顯示樣本數、主課配速與心率的相對差異，以及「僅作趨勢」或「維持」等保守結論。
- WHEN 樣本少於兩筆、路線／溫度／跑步機／坡度被品質檢查排除，THE SYSTEM SHALL 顯示原因與「不調整課表」的降級結論。
- WHEN 心率或步頻資料缺失，THE SYSTEM SHALL 顯示「未提供」，不得以 0 或猜測填補。
- WHEN Garmin 自我評量可用，THE SYSTEM SHALL 將 RPE／感受列為佐證，不要求再次填寫。
- THE SYSTEM SHALL 保存已結束週的當時判讀快照，不以後續資料回寫歷史結論。

## 資料與 API

- 輸入：既有 `coachRunRecords()`、`plannedSessionFor()`、`sessionQualitySignals()`、`postRunVerdict()`、`coachReviewData.autopilot.metrics`、`selfEvaluation`、活動條件品質。
- 輸出：純前端渲染的單堂判讀模型；不新增 API、不寫回 Garmin。
- 驗證：主課範圍必須來自 Garmin 工作步驟；課表對照只使用同日正式課表；數值不可用時顯式降級。
- 錯誤：同步缺段、無相符課表或沒有可比較歷史時保留原始數據與明確說明。

## 安全性與隱私

- 身分驗證／權限：沿用本機訓練頁既有邊界。
- 敏感資料：僅使用既有訓練與恢復摘要，不新增位置資料或外送資料。
- 濫用情境：不得將相關性包裝成醫療或絕對能力結論。

## 驗收標準

- 以截圖中的 6 km 主課為例，結論能說明後段加速、心率由 127 至 158 的累積、主課平均 6:57/km／HR 145 與「兩筆同課型」的比較限制。
- 每個結論都有範圍、數據與限制三者至少之一；沒有「資料足夠」時，不提供進階或調速建議。
- 桌面版不讓判讀區成為空白大卡；手機版先顯示結論與下一步，再折疊證據。
- 沿用現有 `--c-*` token、Card、狀態標籤與按鈕，沒有新色彩或平行資訊架構。

## 驗證計畫

- 單元：涵蓋主課、有／無同課型、缺心率、條件排除與無課表對照。
- 整合：擴充 `scripts/trainer-logic-check.mjs`／`scripts/ui-smoke-check.mjs`，驗證降級與反黑箱文案。
- 視覺：桌面 1440px 與手機 390px 截圖；檢查文字、折疊、狀態與觸控目標。
- 手動：用已同步活動核對主課總距離與各證據所引用數字。
