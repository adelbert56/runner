# 功能規格書：教練週決策可讀圖

## 目標

將既有 Runner 的「同步證據 → 完成判定 → 教練調整 → 歷史隔離」濃縮為一張供跑者、教練與維護者共讀的靜態流程圖；它解釋規則，不宣稱某位跑者的實際同步或週報已完成。

## 範圍

- 產出一份獨立 HTML／內嵌 SVG，沿用 Trainer 的淺綠、深綠、暖橘與繁中排版語言。
- 以五個週期階段、四個固定欄位（問題、輸入、判定、輸出）呈現。
- 清楚說明：同步只補足證據、品質課不可只用總距離認列、新週決策不覆蓋歷史週。

## 非目標

- 不修改 Runner 產品頁面、Garmin 同步、週報或教練演算法。
- 不讀取 Garmin token、原始活動或加密週報。

## 驗收標準

- 圖面在沒有 JavaScript 的情況下完整可讀，SVG 具備可及性標題與描述。
- 不超過 5 個階段、20 個語意儲格；閱讀者能由左至右追到輸出及隔離規則。
- 使用靜態結構檢查，且不寫入產品資料。
