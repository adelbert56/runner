# RACE-SYNC-003 賽事正本異常時保留網站資料

- 目標：正本不存在、JSON 損壞、空陣列或格式不是陣列時，同步程序回傳失敗，不覆寫既有網站副本。
- 人工方向：使用者要求完成先前同意的資料保護與賽事資料一致性工作。
- 風險：中；涉及公開資料產生流程，未改動正式資料或部署。
- 情境：`scripts/sync-race-data.mjs` 原本捕捉任何讀取或解析錯誤後，以空陣列覆蓋網站副本並回傳成功。正本及網站副本現各有未提交變更，不進行實際同步。
- 範圍：同步的輸入防護與隔離測試；非目標為判斷現有賽事各欄位正確性、改正本或推送發布。
- 驗收：缺檔、損壞、空陣列及非陣列輸入均為非零狀態且原檔及網站副本不變；合法輸入仍可同步。
- 驗證：`npm run data:sync:check` 在獨立暫存目錄使用合成資料執行實際同步腳本。
- 回滾：只撤回本卡同步腳本及測試，不觸及既有使用者資料。
