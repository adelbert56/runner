# TRAINER-RESTORE-002 還原前快照與儲存失敗防護

- 類型：資料保存修正；風險：高。人工方向：使用者要求繼續已同意的課程紀錄保護、還原驗證工作。
- 情境：匯入及雲端載入前的快照原本失敗仍繼續；`saveData` 寫入失敗後仍通知同步。`normalizeData` 未保留部分重建標記。
- 範圍：`site/trainer.js`、`trainer-data.js`、`trainer-sync.js`、腳本載入版本及隔離測試；不操作真實課表、遠端帳號或備份。
- 契約：還原前快照必須成功回讀；匯入預覽後持久資料改變時阻擋；儲存失敗不可通知同步、變更目前畫面狀態或更新雲端 revision；保留 recovery manifest。維持既有匯入前快照格式與保存位置。
- 不包含：完整跨分頁交易鎖、異地備份、真實帳號同步與真實備份還原演練。
- 驗證：合成資料測試匯入、回復、快照及儲存失敗、其他分頁變更、雲端失敗；trainer 邏輯及 UI 靜態契約檢查。
- 安全及架構審查：現有 localStorage 仍非獨立備份，兩次讀寫間仍存在競態；不宣稱已完全解決覆寫問題。回滾須保留既有使用者資料及原先未提交變更。
