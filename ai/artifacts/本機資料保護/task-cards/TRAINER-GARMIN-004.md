# TRAINER-GARMIN-004 保護 Garmin 活動並阻止重複摘要

- 方向：使用者要求修復課程紀錄問題並驗證後交付。風險：高，涉及訓練紀錄及跨寫入路徑。
- 事實：獨立備份從 131 筆成長至 317 筆，唯一複合鍵數仍為 131；62 組完全相同的 Garmin 摘要各重複增加，原始活動與摘要可出現在同一天。
- 原因：同步以日期選最後一筆，可能以摘要取代原始活動；既有持久化保護再補回原始活動，造成下一輪重複產生摘要。
- 範圍：Garmin 背景同步依日期優先選人工資料、其次既有摘要，保留活動原始欄位及同日其他活動；不刪除現有記錄、不改備份或訓練處方。
- 驗收：重複同步後筆數穩定；有和沒有活動 ID 的原始活動及同日不同活動、手動紀錄均不覆寫；與既有保存保護共同執行。
- 驗證：`node scripts/trainer-garmin-log-safety-check.mjs`；執行 trainer 邏輯及 UI 契約檢查。
- 限制：既有重複資料不在此卡自動刪除，避免誤刪不同活動；修正只有頁面載入新版本後才生效。
