# LOCAL-BOUNDARY-001 本機服務檔案邊界

- 類型：後端安全修正；風險：高（網路與檔案邊界）。
- 人工方向：使用者同意先執行盤點提出的資料保護與本機服務安全改善。
- 目標：本機網站保留既有主要頁面、報名 API、賽事備援與課表重建設定，避免任意讀取工作目錄及對外網卡監聽。
- 情境：`site/server.mjs` 原本以工作目錄為靜態根目錄並監聽所有介面；報名 API 的限制無法涵蓋靜態檔案。`site/trainer-local-backup.js` 依賴重建設定。
- 範圍：本機 HTTP 服務、針對性驗證；不修改個資、課表、備份或雲端設定，不重啟使用者現有服務。
- 契約：僅監聽 IPv4／IPv6 loopback；靜態資源限定 `site`、`local/registration`、賽事資料庫與重建設定；其他路徑回 404；報名 API 權限不變。真實路徑須留在允許範圍，防止符號連結越界。
- 驗收：頁面與必要資料可讀、敏感檔及工作目錄其他檔案不可讀、外部 Origin 不可取報名 API；獨立連接埠測試及既有檢查。
- 架構與安全審查：採用現有 Node HTTP 服務及檔案路徑，不加依賴；受限於靜態目錄仍須維持無敏感資料的發布規範。
- 回滾：還原本卡對 `site/server.mjs` 的變更；保留其他未提交的備份啟動變更與使用者資料。
- 狀態：實作與隔離測試中；現行 4173 行程尚未重啟，人工環境驗收待完成。
