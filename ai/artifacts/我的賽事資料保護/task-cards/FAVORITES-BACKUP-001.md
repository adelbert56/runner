# FAVORITES-BACKUP-001 我的賽事資料備份

- 人工方向：使用者選定 A；高風險，針對收藏與報名狀態的本機持久化；不含訓練資料、個資與雲端。
- 目標：匯出與還原賽事收藏、已報名、文章收藏，並預覽筆數、先保存快照及保護並發變更。
- 變更範圍：`site/index.html`、`site/app.js`、新增資料保護程式及測試；沿用既有按鈕樣式，不改賽事或訓練邏輯。
- 契約：版本化 JSON、限制檔案大小、三個字串陣列；預覽確認前不變更儲存。寫入前快照回讀失敗或版本變動停止；部分寫入失敗嘗試復原並明示失敗。瀏覽器儲存不可用應提示。
- 驗證：隔離測試格式與損壞檔、成功、取消、快照與部分寫入失敗、跨分頁變更；執行 `npm run check`。專案禁止瀏覽器控制，互動及手機截圖須標示尚未實測。
- 回滾：移除新增入口與程式，不刪使用者 localStorage；保留匯出檔與快照。
