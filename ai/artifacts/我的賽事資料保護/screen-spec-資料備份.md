# 畫面規格：我的賽事資料備份

## Metadata

- 功能：我的賽事資料保護；畫面：資料與備份；狀態：草稿。

## 目的與版面

讓跑者知道目前保存範圍，匯出檔案並在還原前比較。主要動作是匯出；次要動作是選擇備份並預覽。A 由我的賽事摘要進入，B 由賽事工具列進入，後續預覽內容一致。

## 狀態

| 狀態 | 行為與訊息 | 驗證 |
|---|---|---|
| 預設 | 顯示收藏、已報名、文章收藏數量；匯出與還原入口 | DOM／互動 |
| 讀取中 | 動作停用，顯示「正在讀取備份」 | 延遲檔案測試 |
| 空資料 | 說明尚無收藏或報名，可匯出空資料 | 空資料測試 |
| 預覽 | 比較目前與備份各類筆數，明示確認會取代目前資料 | 匯入測試 |
| 錯誤 | 無效檔／快照失敗／資料已變動均顯示原因且不寫入 | 失敗路徑 |
| 停用／不支援 | localStorage 不可用時停用寫入並說明 | 權限受限環境 |
| 手機 | 按鈕堆疊，表格可閱讀，不橫向溢出 | 390px 版面 |

- 重用 `--ink`、`--muted`、`--surface`、`--line`、`--green-dark`、`--radius`；既有 Button、Card、Input。
